# GPT-2 Small pretrained model

The example uses OpenAI's **GPT-2 Small**, distributed as converted OpenNN
weights by Artelnics at
[Artelnics/gpt2-small-opennn](https://huggingface.co/Artelnics/gpt2-small-opennn).
The identical files were originally published as `gpt2-weights-v1` on
2026-07-10 and migrated to Hugging Face on 2026-09-30.
Weights are downloaded at run time and are not committed
to the OpenNN repository or included in the library installation package.

## Converted release and files

The Artelnics release specifies `TextGenerationNetwork` dimensions
`256, 50258, 768, 12, 3072, 12`. Its model vocabulary reserves `[PAD]` at index
zero in addition to the 50,257 original GPT-2 tokens. The tokenizer files come
from GPT-2: the vocabulary mapping matches
[openai-community/gpt2 at 607a30d783dfa663caf39e06633721c8d4cfcd7e](https://huggingface.co/openai-community/gpt2/tree/607a30d783dfa663caf39e06633721c8d4cfcd7e),
and `merges.txt` matches byte-for-byte. The vocabulary JSON serialization differs
but the token-to-ID mapping is identical.

## Using the example and redistributing the download

CMake copies this notice and `LICENSE_GPT2.txt` to `../data/gpt2` beside the
downloaded files before the example runs. Build target `gpt2` and run it from
the executable directory on a CUDA GPU. It accepts one optional prompt argument,
defaults to `Artificial intelligence`, and generates at most 40 new tokens.

If downloading the assets separately, copy the two notices alongside them.
The Hugging Face repository includes both notices and links to them from its
model card. Redistributed copies must preserve the original licence text and
attribution, including the original licence's generated-content paragraphs.
